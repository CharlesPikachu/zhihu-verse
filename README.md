# ZHIHU://VERSE

ZHIHU://VERSE 是一个由 Zhihu CLI 驱动的交互式知乎实验场，把搜索、直答、热榜和个人内容变成知识宇宙、小游戏与可视化体验。

## 运行与 Access Secret

本地运行：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

第一次可以点 **ENTER DEMO** 直接体验。要使用真实知乎数据，点右上角 **OFFLINE / DEMO** 或首页 **CONNECT ZHIHU**，填入自己的 **Access Secret** 即可。

个人创作、关注、收藏、收藏夹等接口默认读取当前调用方本人的公开数据，因此本项目统一使用 Access Secret。

如果浏览器直连开放平台遇到 CORS，可以部署 `worker/` 里的 Cloudflare Worker，并把地址填到 `config.js`：

```js
window.ZHIHU_VERSE_CONFIG = {
  proxyUrl: 'https://your-worker.workers.dev',
  defaultTransport: 'auto'
};
```

GitHub Pages 已包含 `.github/workflows/deploy-pages.yml`，仓库 Pages Source 选择 **GitHub Actions** 即可部署。

开放平台文档：<https://developer.zhihu.com/docs>

## 01. EXPLORE — 双域探索

**是什么**：把普通搜索结果变成可以继续展开的空间节点。

**用了什么**：知乎搜索、全网搜索、直答。

**怎么用**：输入一个问题或主题，选择“知乎 / 全网 / 混合”后点击 **LAUNCH**。点节点可以看摘要、作者、互动信息和原始来源；**EXPAND** 会以当前节点继续搜索，**ZHIDA EXPLAIN** 会让直答解释这个节点。

## 02. COLLIDER — 知识对撞

**是什么**：寻找两个看起来不相关的概念之间的知识路径。

**用了什么**：直答、知乎搜索。

**怎么用**：在左右两侧输入两个概念，点击 **COLLIDE**。直答先给出中间路径，再用知乎搜索逐个验证这些中间节点。

## 03. GRAPH — 知识图谱

**是什么**：围绕一个主题自动展开知乎与全网的双源知识图谱。

**用了什么**：直答、知乎搜索、全网搜索。

**怎么用**：输入主题，选择图谱深度后点击 **BUILD GRAPH**。系统先拆出几个关键分支，再为每个分支补充真实搜索结果；点任意节点可以查看详情和来源。

## 04. ZHIDA ARENA — 直答问答

**是什么**：由知乎直答动态生成的五题知识挑战。

**用了什么**：直答；“根据我的收藏”模式还会读取用户收藏和收藏夹内容。

**怎么用**：可以选择 **自选主题**，输入主题后开始答题；也可以选择 **根据我的收藏**，网页会先读取当前账号的收藏，再让直答根据这些内容出题。每题答完立即显示解释、得分和连胜。

## 05. RUNNER — 问题跑酷

**是什么**：类似 Chrome 小恐龙的跑酷小游戏，障碍物由知乎热榜和搜索问题生成。

**用了什么**：热榜、知乎搜索。

**怎么用**：点击 **START / RESTART** 开始。地面问题按空格、↑ 或点击画布跳跃，支持二段跳；出现紫色的空中问题时，按 ↓ 或 S 下蹲躲避。前几十分只会出现地面题，之后才逐渐加入空中题。**REFRESH QUESTION POOL** 可以刷新题库。

## 06. MY MEMORY — 记忆星球

**是什么**：把自己的创作、收藏、收藏夹和关注整理成一个可探索的个人内容星球。

**用了什么**：用户内容、用户关注、用户收藏、收藏夹列表、收藏夹内容、直答。

**怎么用**：连接 Access Secret 后点击 **ASSEMBLE PLANET**。拖动 **TIME DEPTH** 可以裁剪时间范围，**AI THEME SCAN** 会用直答概括当前内容中的主要主题。

## 07. RECAP — 年度 / 月度回顾

**是什么**：根据自己的公开创作和收藏数据生成年度或月度回顾。

**用了什么**：用户内容、用户收藏、收藏夹内容、直答。

**怎么用**：选择年份和月份，点击 **GENERATE**。页面会整理活动时间线、关键词和内容高光；**ZHIDA COMMENT** 可以生成一段简短回顾；**EXPORT LONG POSTER** 会一键下载一张 1080×2480 的分享长图 PNG。

## 08. LIVE — 热榜超新星

**是什么**：把一次次热榜快照连成时间变化，而不是只看当前榜单。

**用了什么**：知乎热榜。

**怎么用**：点击 **SCAN NOW** 保存当前热榜。积累两份以上快照后，可以看到排名上升和下降；快速上涨会触发超新星效果，**REPLAY** 可以回看之前保存的快照。

## 09. TOOLS LAB — PDF / PPT

**是什么**：开放平台 PDF 解析和 PPT 生成能力的操作面板。

**用了什么**：PDF 文件上传、PDF 解析任务创建/查询、PPT 生成任务创建/查询。

**怎么用**：PDF 区选择文件后点 **UPLOAD + PARSE**，再点 **CHECK STATUS** 查询结果；PPT 区输入知乎回答或专栏文章链接、选择页数后点 **CREATE PPT**，再用 **CHECK STATUS** 查询任务状态。
